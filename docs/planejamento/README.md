# 📋 Planejamento de Conteúdo

Esta pasta contém documentos de planejamento interno para posts e melhorias do blog.

## 📁 Estrutura

- `proximos-posts.md` - Lista de ideias e posts planejados
- `2025.md` - Planejamento específico para 2025

## ⚠️ Importante

Os arquivos desta pasta são para uso interno e **não são publicados** no site.

Para criar um post publicável, mova o conteúdo para `_posts/YYYY/` com o formato correto.

## 📝 Template para Planejamento de Post

```markdown
## Título do Post

**Status:** Planejado | Em Progresso | Concluído
**Data Prevista:** YYYY-MM-DD
**Categoria:** [Categoria]
**Tags:** tag1, tag2, tag3

### Resumo
Descrição breve do que será abordado no post.

### Tópicos
- Tópico 1
- Tópico 2
- Tópico 3

### Recursos Necessários
- Imagens/Screenshots
- Código de exemplo
- Referências
```
